grid-aware

A small API that combines Electricity Maps (global) with the UK NESO Carbon Intensity API (DNO region) behind one normalized endpoint.

Read about the scope and caveats on the project page and get in touch with questions or feedback.

Try it

curl 'https://your-deployed-url.com/v1/intensity?zone=FR' \
  -H 'Origin: https://your-allowed-site.example'

Data endpoints (/v1/*) require the calling origin to be on this deployment's allowlist, to protect its own Electricity Maps quota - get in touch to have yours added or deploy the code yourself.

Use it on a page

The @web-components/grid-aware package sets a data-grid-aware attribute on <html> reflecting the current intensity band, which your CSS and scripts can respond to: 

<script type="module"
        src="https://esm.sh/jsr/@web-components/grid-aware/browser"
        data-api-base-url="https://your-deployed-url.com"></script>

<style>
  html[data-grid-aware="high"] video { display: none; }
</style>

This is a JS module, so it's deferred by the browser and the band gets applied after the page has already started rendering; it can flash default styling. To avoid that, a plain (non-module) blocking build is available to place early in <head>. It fetches synchronously and sets data-grid-aware before the rest of the page paints, at the cost of stalling the page load on the first request (a cached response is used on subsequent loads): 

<script src="https://your-deployed-url.com/grid-aware/blocking.js"
        data-api-base-url="https://your-deployed-url.com"></script>

API reference v1.1.2

Combined global (Electricity Maps) and UK-regional (NESO) grid carbon intensity API.

Raw spec: /openapi.json

GET /v1/intensity

Get combined grid carbon intensity

Routes to NESO for GB and to Electricity Maps for everything else. Defaults to Cloudflare-detected location (postcode or city).

GB DNO region detail, when known. id/name are only ever present for NESO regional responses; nation may be present on its own when only a coarser signal (e.g. Cloudflare's detected nation) was available.
location.region.unknown
boolean
True when none of id/name/nation could be determined for this request.

carbonIntensity
{
  value: number
  unit: "gCO2eq/kWh"
  type: "actual" | "forecast" | "estimated" | "unknown"
  band: "low" | "moderate" | "high" | "very-high" | "unknown"

The carbon intensity figure itself.
carbonIntensity.value
number
The carbon intensity figure, in `unit`. `null` when `band` is "unknown".
carbonIntensity.type
"actual" | "forecast" | "estimated" | "unknown"
"actual" = measured (NESO national, when available), "forecast" = NESO's forward estimate (national fallback and all regional data), "estimated" = Electricity Maps' modeled figure, "unknown" = an upstream provider failed or returned unusable data.
carbonIntensity.band
"low" | "moderate" | "high" | "very-high" | "unknown"
Coarse category for the value. GB responses use NESO's own index (recalculated by NESO each year against GB's own grid); other zones use generic, approximate global thresholds since no equivalent official index exists worldwide. "unknown" means an upstream provider failed or returned unusable data, see `fallback.reason`.
generationMix
{
  fuel: string
  percentage: number
}[]
Fuel mix behind this figure. Only returned for NESO regional responses.
forecast
{
  datetime: string
  validTo?: string
  value: number
  type: "actual" | "forecast" | "estimated" | "unknown"
  band: "low" | "moderate" | "high" | "very-high" | "unknown"
  generationMix?: {
    fuel: string
    percentage: number

}[]
Near-future periods covering the requested horizon window (NESO: 30-minute periods; Electricity Maps: hourly), including the period already summarized above. Present only when `horizon` is "24h" or "48h".
forecast.datetime
string
Start of this period, ISO 8601 UTC.
forecast.validTo
string
End of this period, when known.
forecast.value
number
The carbon intensity figure, in `unit`. `null` when `band` is "unknown".
forecast.band
"low" | "moderate" | "high" | "very-high" | "unknown"
Coarse category for the value. GB responses use NESO's own index (recalculated by NESO each year against GB's own grid); other zones use generic, approximate global thresholds since no equivalent official index exists worldwide. "unknown" means an upstream provider failed or returned unusable data, see `fallback.reason`.
forecast.generationMix
{
  fuel: string

Fuel mix for this period. Only present for NESO regional forecasts.
fallback
{
  reason: string
}
Present when a GB request was redirected from NESO to Electricity Maps because the caller wasn't UK-origin, or when the intended upstream provider failed and `band`/`type` fell back to "unknown".

GET /v1/zones

List Electricity Maps zones

Parameters

No parameters.

Responses

  zoneName?: string
  countryName?: string
} }

  error: {
    message: string
    provider?: "electricitymaps" | "neso"
  }
}

  error: {
